## 1. 产品概述

### 1.1 产品定位

**国清商城**是基于若依（RuoYi-Vue）二次开发的轻量级 B2C 电商系统，包含：

- **B 端管理后台**：运营人员管理分类、商品、订单
- **C 端商城**：买家浏览、搜索、加购、下单、支付（模拟）、查单

同一套账号体系，管理员与普通买家角色分离；C 端与 B 端共用登录入口，按角色跳转不同界面。

### 1.2 目标用户

| 角色 | 说明 | 典型账号 |
|------|------|----------|
| 超级管理员 | 管理后台 + 可逛商城 | `admin` |
| 普通买家 | 仅 C 端购物 | `ry` 或微信/支付宝模拟登录自动注册 |
| 运营人员 | 实际上与超级管理员共用 B 端权限（当前版本） | `admin` |

### 1.3 产品目标（v1.0）

- 支持商品上架、分类、上下架、库存管理
- 支持完整下单流程（购物车 → 结算 → 模拟支付 → 发货 → 收货）
- C 端响应式：手机 H5 + PC 浏览器同一地址自适应
- 支持本地/服务器 Docker 部署，可扩展微信真登录

### 1.4 不在 v1.0 范围

- 真实微信/支付宝**支付**（当前为模拟支付）
- SKU 多规格、优惠券、积分、运费模板
- 买家端申请退款（仅管理员后台退款）
- 未付款订单自动超时取消
- 独立小程序 / APP（当前为 Web H5 + PC）

## 3. 功能需求

### 3.1 B 端 — 商品分类

**入口**：管理后台 → 商城管理 → 商品分类  
**权限**：`mall:category:*`（默认仅超级管理员）

| 功能 | 需求说明 |
|------|----------|
| 列表 | 展示分类名称、排序、状态、备注 |
| 搜索 | 按分类名称、状态筛选 |
| 新增 | 填写分类名称、父分类 ID、显示顺序、状态 |
| 编辑 | 修改上述字段 |
| 删除 | 物理删除（需注意是否有关联商品） |
| 状态 | `0` 正常 / `1` 停用；停用后 C 端不展示 |

**数据字段**：`categoryId`、`parentId`、`categoryName`、`orderNum`、`status`、`remark`

---

### 3.2 B 端 — 商品管理

**入口**：管理后台 → 商城管理 → 商品管理  
**权限**：`mall:product:*`

| 功能 | 需求说明 |
|------|----------|
| 列表 | 主图、名称、分类、货号、价格、库存、销量、状态 |
| 搜索 | 商品名称、货号、分类、状态 |
| 新增/编辑 | 见下表字段 |
| 删除 | 软删除（`del_flag=2`） |
| 上下架 | `0` 上架 / `1` 下架；下架后 C 端不可见 |

**商品字段**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 商品名称 | 是 | 最长 128 字 |
| 分类 | 是 | 关联商品分类 |
| 货号 | 否 | 商品编码 |
| 主图 | 否 | 列表/详情封面 |
| 相册 | 否 | 最多 8 张，逗号分隔 |
| 视频 | 否 | mp4/avi/rmvb，≤50MB |
| 销售价格 | 是 | 小数 |
| 库存 | 是 | 整数 |
| 销量 | 否 | 系统累计 |
| 状态 | 是 | 上架/下架 |
| 描述 | 否 | 详情页展示 |

---

### 3.3 B 端 — 订单管理

**入口**：管理后台 → 商城管理 → 订单管理  
**权限**：`mall:order:*`

| 功能 | 触发条件 | 说明 |
|------|----------|------|
| 查看详情 | 任意 | 订单信息 + 商品明细 |
| 发货 | 状态=已付款 | 变为「已发货」，记录发货时间 |
| 完成 | 状态=已发货 | 变为「已完成」 |
| 取消 | 待付款/已付款 | 变为「已取消」 |
| 退款 | 已付款/已发货 | 变为「已退款」，**恢复库存** |
| 删除 | 任意 | 删除订单及明细 |

**订单状态定义**：

| 状态码 | 名称 | 说明 |
|--------|------|------|
| 0 | 待付款 | 用户已下单，未支付 |
| 1 | 已付款 | 用户已模拟支付，待发货 |
| 2 | 已发货 | 管理员已发货，待收货 |
| 3 | 已完成 | 交易完成 |
| 4 | 已取消 | 订单关闭 |
| 5 | 已退款 | 管理员退款，库存已恢复 |

---

### 3.4 C 端 — 商城首页

**路由**：`/shop/home`  
**登录**：不需要（浏览、搜索、排序）

| 功能 | 需求说明 |
|------|----------|
| 商品列表 | 分页展示，默认每页 12 条 |
| 分类筛选 | 侧边栏（PC）/ 横向标签（手机） |
| 搜索 | 按商品名称模糊搜索 |
| 搜索历史 | 本地保存最近 10 条，可清空、可点击复搜 |
| 搜索推荐 | 热销商品名 + 分类名，点击即搜 |
| 排序 | 综合 / 价格升序 / 价格降序 / 销量 / 最新上架 |
| 主题色 | 5 套配色可选，持久化到浏览器 |
| 夜间模式 | 顶栏一键切换，持久化到浏览器 |

**布局**：

- 手机：底部 Tab（首页 / 购物车 / 我的）+ 双列商品
- PC：顶栏导航 + 左侧分类 + 自适应商品网格

---

### 3.5 C 端 — 商品详情

**路由**：`/shop/product/:productId`  
**登录**：不需要（浏览）

| 功能 | 需求说明 |
|------|----------|
| 展示 | 相册轮播、视频、名称、价格、库存、销量、描述 |
| 数量 | 可选 1～库存上限 |
| 加入购物车 | **需登录** |
| 立即购买 | **需登录**，跳转结算页 |

---

### 3.6 C 端 — 购物车

**路由**：`/shop/cart`  
**登录**：需要

| 功能 | 需求说明 |
|------|----------|
| 列表 | 展示已加购商品、单价、数量、小计 |
| 勾选 | 支持全选/单选 |
| 改数量 | 不超过库存 |
| 删除 | 移除条目 |
| 结算 | 跳转确认订单，仅结算已勾选项 |

---

### 3.7 C 端 — 确认订单 / 支付

**路由**：`/shop/checkout`  
**登录**：需要

| 功能 | 需求说明 |
|------|----------|
| 来源 | 购物车勾选 或 立即购买 |
| 收货信息 | 收货人、手机号、地址（必填）；备注（选填） |
| 提交订单 | 生成待付款订单，**此时扣减库存** |
| 模拟支付 | 确认后将订单变为「已付款」，无真实支付通道 |

---

### 3.8 C 端 — 我的 / 订单 / 资料

**路由**：`/shop/mine`、`/shop/orders`、`/shop/orders/:id`、`/shop/profile`

| 页面 | 功能 |
|------|------|
| 我的 | 订单入口、资料入口、主题/夜间模式；未登录显示登录引导 |
| 我的订单 | Tab：全部 / 待付款 / 待发货 / 待收货 / 已完成 / 退款·取消 |
| 订单操作 | 待付款：去支付、取消；待收货：确认收货 |
| 我的资料 | 修改昵称、手机、邮箱、性别；登录账号只读 |

---

### 3.9 登录与账号

**路由**：`/login`

| 方式 | 说明 |
|------|------|
| 账号密码 | 若依标准登录，支持验证码 |
| 微信登录 | 未配置 AppId 时走**模拟登录**，自动注册 C 端用户 |
| 支付宝登录 | 同上（模拟）；真实 OAuth 需后续接入 SDK |
| 跳转规则 | 管理员 → 后台首页；普通用户 → 我的；带 `redirect` 参数则回原页面 |

**C 端访问控制**：

- 非管理员访问 B 端路由会被重定向到 `/shop/home`
- C 端页面可匿名打开，加购/下单 API 需 Token

## 4. 业务流程

### 4.1 买家购物流程

```
浏览首页 → 搜索/筛选 → 商品详情 → [登录] → 加购/立即购买
    → 购物车勾选 → 结算填地址 → 提交订单(待付款)
    → 模拟支付(已付款) → [管理员发货] → 确认收货(已完成)
```

### 4.2 管理员履约流程

```
订单管理 → 筛选「已付款」→ 发货 → 筛选「已发货」→ 完成
（或等待买家确认收货自动完成）

异常：待付款/已付款 → 取消；已付款/已发货 → 退款（恢复库存）
```

### 4.3 订单状态机

```
                    ┌──────────┐
                    │ 待付款 0 │
                    └────┬─────┘
           取消(买家)     │  支付(买家)
                ┌────────┼────────┐
                ▼                 ▼
          ┌──────────┐      ┌──────────┐
          │ 已取消 4 │      │ 已付款 1 │
          └──────────┘      └────┬─────┘
                                 │ 发货(管理员)
                                 ▼
                           ┌──────────┐
                           │ 已发货 2 │
                           └────┬─────┘
                    退款(管理员) │  确认收货(买家) / 完成(管理员)
                ┌───────────────┼───────────────┐
                ▼                               ▼
          ┌──────────┐                    ┌──────────┐
          │ 已退款 5 │                    │ 已完成 3 │
          └──────────┘                    └──────────┘
```

## 7. 已知限制与风险（v1.0）

| 项 | 说明 | 影响 |
|----|------|------|
| 模拟支付 | 点击支付即成功，无资金流转 | 不可用于真实收款 |
| 库存时机 | 下单时扣库存，非支付后 | 未付款订单会占用库存 |
| 无超时取消 | 待付款订单不会自动关闭 | 需买家手动取消或管理员处理 |
| B 端取消不恢复库存 | 仅退款操作恢复库存 | 误取消已付款订单需注意 |
| 无 SKU | 一商品一价一库存 | 多规格商品需拆成多个 SKU 商品 |
| 退款仅 B 端 | 买家不能自助申请退款 | 需联系客服/管理员 |
| 分类管理 | 后台为平铺表格，父 ID 手填 | 多级分类操作不够直观 |
