## 1. 快速开始

### 1.1 访问地址

| 用途 | 本地开发 | 服务器部署 |
|------|----------|------------|
| **C 端商城（买家）** | http://localhost/shop/home | http://你的域名或IP/shop/home |
| **B 端后台（管理）** | http://localhost | http://你的域名或IP/ |
| **登录页** | http://localhost/login | 同上 + `/login` |

### 1.2 第一次使用（管理员）

1. 用浏览器打开 **B 端后台** 地址
2. 使用管理员账号登录（见 [2. 账号说明](#2-账号说明)）
3. 左侧菜单进入 **商城管理**：
   - 先建 **商品分类**
   - 再建 **商品** 并上架
4. 打开 **C 端商城** 地址，确认商品能正常展示
5. 用买家账号走一遍：加购 → 下单 → 支付 → 后台发货 → 确认收货

### 1.3 第一次使用（买家）

1. 打开 **C 端商城** `/shop/home`
2. 无需登录即可浏览、搜索商品
3. 购买时点击「加入购物车」或「立即购买」，按提示登录
4. 登录后完成下单与模拟支付，在 **我的 → 我的订单** 查看进度

## 2. 账号说明

### 2.1 内置测试账号

| 账号 | 密码 | 能做什么 |
|------|------|----------|
| **admin** | admin123 | 管理后台（分类/商品/订单）+ 也可逛商城 |
| **ry** | admin123 | **仅 C 端购物**，看不到管理后台菜单 |

> **建议**：自己测试购物流程用 `ry`；日常上架、发货用 `admin`。  
> **上线前务必修改默认密码！**

### 2.2 微信 / 支付宝登录

- 登录页底部有 **微信登录**、**支付宝登录** 按钮
- **未配置正式 AppId 时**（本地/测试环境默认）：点击后自动创建买家账号并登录，无需扫码
- **正式环境**：需完成服务器部署、域名备案，并在后台配置微信开放平台（详见 [deploy-from-zero.md](deploy-from-zero.md) 阶段 11）

### 2.3 登录后会跳转到哪？

| 账号类型 | 默认跳转 |
|----------|----------|
| 管理员 | 管理后台首页 |
| 普通买家 | 商城「我的」页 |
| 任意账号 | 若 URL 带 `redirect` 参数，登录后回到原页面（如购物车、结算页） |

## 3. 买家使用指南（C 端商城）

### 3.1 界面说明

**手机端**

- 顶部：商城名称、夜间模式、主题色
- 底部 Tab：**首页** | **购物车** | **我的**

**电脑端**

- 顶部导航：首页 | 购物车 | 我的 | 登录/昵称
- 首页左侧：商品分类
- 主区域：Banner、搜索、商品列表

### 3.2 浏览与搜索商品

**路径**：首页 `/shop/home`

1. **按分类看**：点击分类名称（手机为横向标签，电脑为左侧列表）
2. **搜索**：在搜索框输入商品名称 → 回车或点「搜索」
3. **搜索历史**：搜索框下方会显示最近搜过的词，点击可再次搜索；点「清空」清除历史
4. **搜索推荐**：展示热销商品名和分类名，点击即可搜索
5. **排序**（电脑端为顶部胶囊按钮，手机为下拉框）：
   - 综合 / 价格低 / 价格高 / 销量 / 最新
6. **点商品卡片** 进入详情页

### 3.3 商品详情与购买

**路径**：`/shop/product/商品ID`

1. 查看图片、视频、价格、库存、描述
2. 选择购买数量
3. 两种购买方式：
   - **加入购物车**：先进购物车，可继续逛再买
   - **立即购买**：直接去结算

> 以上操作需要登录。未登录时会跳转到登录页，登录后自动回到当前页面。

### 3.4 购物车

**路径**：`/shop/cart`

1. 勾选要买的商品（可全选）
2. 修改数量（不能超过库存）
3. 不需要的点击删除
4. 点 **结算** 进入确认订单

未登录时购物车为空，并提示登录。

### 3.5 下单与支付

**路径**：`/shop/checkout`

1. 核对商品与金额
2. 填写 **收货人**、**手机号**、**收货地址**（必填）
3. 可选填 **备注**
4. 点 **提交订单**
5. 弹出提示「是否立即支付」→ 点确定完成 **模拟支付**

> 当前版本为 **模拟支付**，不会产生真实扣款。正式收款需后续接入微信/支付宝支付。

支付成功后，订单变为「待发货」，等待商家发货。

### 3.6 我的订单

**路径**：`/shop/mine` → **我的订单**，或 `/shop/orders`

**订单状态说明**：

| 状态 | 你能做什么 |
|------|------------|
| 待付款 | 去支付、取消订单 |
| 待发货 | 等待商家发货 |
| 待收货 | 确认收货 |
| 已完成 | 交易结束 |
| 已取消 / 已退款 | 查看记录 |

**Tab 筛选**：全部、待付款、待发货、待收货、已完成、退款·取消

点订单可进入 **订单详情**，查看商品明细、收货信息、状态说明。

### 3.7 我的资料

**路径**：`/shop/mine` → **我的资料**

可修改：昵称、手机号、邮箱、性别  
登录账号名不可改。

### 3.8 夜间模式与主题色

- **夜间模式**：顶栏 **月亮/太阳** 图标，**点一下即切换**，设置会保存在本浏览器
- **主题色**：顶栏 **画笔** 图标，可选活力橙、青绿、蔚蓝、酒红、紫韵等配色

## 4. 管理员使用指南（B 端后台）

> 以下功能需使用 **admin** 或具备商城管理权限的账号登录 B 端后台。

### 4.1 登录后台

1. 访问 http://localhost（或你的服务器地址）
2. 账号 `admin`，密码 `admin123`（上线后请修改）
3. 左侧菜单找到 **商城管理**

若看不到「商城管理」，说明当前账号无权限，请换 admin 账号。

### 4.2 商品分类管理

**菜单**：商城管理 → 商品分类

#### 新建分类

1. 点 **新增**
2. 填写：
   - **分类名称**（必填）
   - **父分类 ID**：顶级分类填 `0`；子分类填父分类的数字 ID（在列表中查看）
   - **显示顺序**：数字越小越靠前
   - **状态**：正常 / 停用
3. 点 **确定**

#### 日常操作

| 操作 | 步骤 |
|------|------|
| 搜索 | 输入分类名称或选状态 → 搜索 |
| 修改 | 选中一条 → 修改 |
| 删除 | 选中 → 删除（确认无关联商品） |
| 停用 | 修改状态为「停用」，C 端不再展示 |

### 4.3 商品管理

**菜单**：商城管理 → 商品管理

#### 上架新商品

1. 点 **新增**
2. 必填：**商品名称**、**分类**、**销售价格**、**库存**
3. 建议填写：
   - **主图**：列表和详情封面
   - **相册**：多张图片，逗号分隔（最多 8 张）
   - **视频**：mp4 等格式
   - **描述**：详情页文字介绍
   - **货号**：内部编码，方便搜索
4. **状态** 选 **上架**
5. 点 **确定**

#### 日常操作

| 需求 | 操作 |
|------|------|
| 临时不卖 | 编辑 → 状态改为 **下架** |
| 改价/改库存 | 编辑对应字段 |
| 查商品 | 按名称、货号、分类、状态搜索 |
| 删除商品 | 删除（软删除，C 端不可见） |

#### 注意

- 库存为 0 时买家无法下单
- 下架商品在 C 端不显示，已有链接会提示「不存在或已下架」

### 4.4 订单管理

**菜单**：商城管理 → 订单管理

#### 订单状态与你要做的事

| 状态 | 含义 | 管理员操作 |
|------|------|------------|
| 待付款 | 买家已下单未付 | 一般等买家支付；可 **取消** |
| 已付款 | 买家已支付 | 点 **发货** |
| 已发货 | 已发出 | 可点 **完成**，或等买家确认收货 |
| 已完成 | 交易结束 | 归档查看 |
| 已取消 | 已关闭 | — |
| 已退款 | 已退款 | 库存已自动恢复 |

#### 典型发货流程

1. 打开订单管理，状态筛 **已付款**
2. 核对收货人、地址、商品
3. 线下完成真实发货（快递等）
4. 在系统中点该订单的 **发货**
5. 买家确认收货或你点 **完成** 后，订单变为已完成

#### 取消与退款

| 场景 | 操作 | 库存 |
|------|------|------|
| 待付款不想要 | **取消** | 下单时已扣库存，取消不自动恢复* |
| 已付款需关闭 | **取消** 或 **退款** | **退款** 会恢复库存 |
| 已发货需退款 | **退款** | 恢复库存 |

\* v1.0 已知限制：买家取消待付款订单会恢复库存；管理员「取消」已付款订单不自动恢复，请优先使用 **退款**。

#### 查看详情

点 **详情** 可看：订单号、买家账号、金额、收货信息、商品明细、各时间节点。

## 5. 常见问题

### 5.1 买家端

**Q：不登录能买东西吗？**  
不能。可以浏览和搜索，加购、下单必须登录。

**Q：支付后钱去哪了？**  
当前是模拟支付，没有真实资金。上线真实支付需额外开发接入。

**Q：待付款订单会自动取消吗？**  
不会。请手动取消，否则库存一直被占用。

**Q：想退款怎么办？**  
联系管理员在后台操作退款。买家端暂不能自助申请。

**Q：admin 账号逛商城有什么问题？**  
功能上可用，但建议用 `ry` 或微信模拟账号测试买家体验，与管理后台分开。

**Q：手机上看和电脑不一样？**  
正常。同一网址会自动适配：手机有底部 Tab，电脑有顶栏和侧栏。

### 5.2 管理端

**Q：普通用户 ry 能进后台吗？**  
不能。会被重定向到商城首页。

**Q：改了商品 C 端没更新？**  
确认状态是「上架」、分类是「正常」；刷新页面；若用了 CDN/缓存需清缓存。

**Q：发货按钮是灰的？**  
只有 **已付款** 状态才能发货。

**Q：如何备份数据？**  
定期备份 MySQL 数据库（商城表 + 若依系统表）。Docker 部署见 [deploy/README.md](../deploy/README.md)。

### 5.3 部署与登录

**Q：微信登录一直模拟？**  
本地默认 `mock-enabled: true` 且未填 AppId。正式环境需域名、备案、微信开放平台配置，见 [deploy-from-zero.md](deploy-from-zero.md)。

**Q：更多部署问题？**  
见 [deploy-from-zero.md](deploy-from-zero.md)、[git-deploy.md](git-deploy.md)。
