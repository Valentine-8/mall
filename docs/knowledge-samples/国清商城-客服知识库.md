# 国清商城智能客服知识库

> 文档版本：v1.0  
> 适用对象：C 端买家咨询  
> 更新日期：2026-06

---

## 一、商城简介

国清商城是国清旗下的在线购物平台，提供商品浏览、搜索、购物车、下单与订单查询等服务。

- **商城首页**：打开网站后进入「商城」或访问路径 `/shop/home`
- **无需登录即可**：浏览商品、搜索、按分类筛选、切换排序与主题
- **需要登录才能**：加入购物车、立即购买、提交订单、支付、查看我的订单
- **客服方式**：页面右下角浮窗「智能客服」；回复「转人工」或「人工」可转接人工坐席

## 二、如何购物

### 2.1 浏览与搜索商品

1. 在首页可通过左侧（电脑）或顶部标签（手机）选择商品分类。
2. 顶部搜索框输入商品名称关键词，点击搜索或按回车。
3. 排序方式可选：综合排序、价格从低到高、价格从高到低、销量、最新上架。
4. 点击商品卡片进入商品详情页，查看价格、库存、图文介绍。

### 2.2 加入购物车

1. 在商品详情页选择数量（不能超过库存）。
2. 点击「加入购物车」；若未登录会提示先登录。
3. 登录成功后商品加入购物车，可继续购物或前往购物车结算。

### 2.3 立即购买

1. 在商品详情页点击「立即购买」。
2. 登录后进入确认订单页，填写收货人姓名、手机号、收货地址。
3. 确认商品与金额无误后提交订单。

### 2.4 购物车结算

1. 进入「购物车」页面（底部 Tab 或顶部导航）。
2. 勾选要购买的商品，可修改数量或删除不需要的商品。
3. 点击「去结算」，填写收货信息后提交订单。

## 三、订单与支付

### 3.1 订单状态说明

| 状态 | 含义 | 买家可做什么 |
|------|------|----------------|
| 待付款 | 已下单，尚未支付 | 去支付、取消订单 |
| 待发货 | 已支付，商家备货发货中 | 等待发货 |
| 待收货 | 商家已发货，运输中 | 等待收货 |
| 已完成 | 交易完成 | 查看历史记录 |
| 已取消 | 订单已关闭 | 无 |
| 已退款 | 管理员已办理退款 | 无 |

在「我的 → 我的订单」可按 Tab 筛选：全部、待付款、待发货、待收货、已完成、退款·取消。

### 3.2 如何支付

1. 提交订单后，系统会提示是否立即支付。
2. 点击「确定」完成支付（当前为**模拟支付**，不会产生真实扣款）。
3. 支付成功后订单变为「待发货」，请耐心等待商家发货。

### 3.3 待付款订单

- 待付款订单**不会自动取消**，若不需要请手动点击「取消订单」，否则商品库存会被占用。
- 取消待付款订单后，占用的库存会自动释放。

### 3.4 如何查看订单

1. 登录后进入「我的」→「我的订单」。
2. 点击某一订单可查看详情：订单号、商品明细、金额、收货地址、各状态时间。
3. 也可在首页右下角客服浮窗中咨询，客服会引导您到订单页自助查询。

## 四、发货与物流

### 4.1 发货时间

- 买家完成支付（订单变为待发货）后，商家会在 **1～3 个工作日** 内安排发货（节假日顺延）。
- 发货后订单状态变为「待收货」。

### 4.2 物流信息

- 当前版本在订单详情中展示订单状态变更时间。
- 如需查询具体快递单号，请联系人工客服，或在订单备注中留言。

### 4.3 长时间未发货

若支付后超过 **3 个工作日** 仍为「待发货」，请通过智能客服回复「转人工」，由人工坐席为您核实处理。

## 五、退换货与退款

### 5.1 退款说明

- 买家端暂不支持自助申请退款，需联系客服或人工坐席。
- 在智能客服对话中回复「转人工」即可接入人工。
- 管理员审核通过后，订单变为「已退款」，商品库存会恢复。

### 5.2 可退款情形（一般规则）

1. **未发货**：已付款但商家尚未发货，可申请全额退款。
2. **已发货**：需说明原因（如商品破损、发错货、与描述严重不符等），由人工审核后处理。
3. **已完成**：原则上不支持无理由退货；质量问题请在收货后 **7 天内** 联系人工客服。

### 5.3 换货说明

- 换货需先联系人工客服说明订单号与问题。
- 换货流程：核实订单 → 买家寄回（如需）→ 商家补发或换发。
- 具体以人工客服答复为准。

### 5.4 以下情况通常不支持退换

- 买家主观原因不喜欢、买错型号（非商家发错）。
- 已使用、已拆封且影响二次销售的特殊商品（如定制类）。
- 超过售后时效未联系客服。

## 六、账号与登录

### 6.1 登录方式

- **账号密码登录**：在登录页输入用户名和密码。
- **微信登录 / 支付宝登录**：点击对应按钮；测试环境可能为模拟登录，正式环境需扫码授权。

### 6.2 登录后跳转

- 普通买家默认进入商城「我的」页。
- 若从购物车、结算页跳转登录，成功后会回到原页面继续操作。

### 6.3 忘记密码

请联系商城管理员在后台重置密码，或通过注册页重新注册新账号（若开放注册）。

### 6.4 不登录能做什么

- 可以：浏览首页、搜索商品、查看商品详情、切换主题与夜间模式。
- 不可以：加购、下单、支付、查看个人订单。

## 七、购物车与库存

### 7.1 库存不足

- 加购或改数量时若超过库存，系统会提示库存不足。
- 结算前请刷新页面确认最新库存。

### 7.2 购物车商品失效

- 若商品已下架或库存为 0，购物车中可能无法勾选或结算，请删除后选购其他商品。

### 7.3 价格变动

- 下单时以提交订单时的页面价格为准；已生成待付款订单的价格一般不变。

## 八、智能客服使用说明

### 8.1 如何打开客服

- 在商城任意页面右下角点击客服浮窗图标即可对话。

### 8.2 智能客服能回答什么

- 购物流程、订单状态含义、支付与发货一般规则。
- 退换货政策概要、登录与账号问题。
- 根据本知识库内容回答与国清商城相关的问题。

### 8.3 如何转人工

在对话框输入以下任一关键词即可转人工：

- 转人工
- 人工
- 客服
- 真人

转人工后可能需要短暂排队，请耐心等待；接入后请提供**订单号**或**下单手机号**以便快速处理。

### 8.4 客服服务时间（建议）

- 智能客服：**7×24 小时** 在线。
- 人工坐席：**工作日 9:00～18:00**（以实际排班为准，非工作时间留言次日回复）。

## 九、常见问题速查

**问：支付后钱扣了吗？**  
答：当前系统为模拟支付，不会产生真实资金扣款。正式收款需平台接入真实支付渠道后生效。

**问：订单可以改地址吗？**  
答：待付款订单建议取消后重新下单；已付款未发货请尽快回复「转人工」由客服尝试修改。

**问：能开发票吗？**  
答：如需发票请转人工，提供订单号、抬头与税号，由工作人员跟进（以商城实际政策为准）。

**问：商品和图片不一致怎么办？**  
答：请保留订单信息与商品照片，联系人工客服核实，符合退换条件的将协助处理。

**问：手机版和电脑版有什么区别？**  
答：功能一致，界面布局不同：手机有底部 Tab（首页/购物车/我的），电脑有顶栏和侧栏分类。

**问：如何修改个人资料？**  
答：登录后进入「我的 → 个人资料」修改昵称等信息（若页面已开放）。

**问：搜索历史在哪里？**  
答：在首页点击搜索框后，会显示最近搜索记录与推荐关键词，可点击复搜或清空历史。

**问：夜间模式怎么开？**  
答：在商城顶栏点击月亮/太阳图标一键切换，设置会保存在本浏览器。

## 十、联系与投诉

- **优先渠道**：商城右下角智能客服 → 需要时输入「转人工」。
- **投诉建议**：请说明订单号、问题描述、期望处理方式，人工坐席会记录并反馈。
- **紧急问题**：涉及资金异常（正式支付上线后）、账号被盗等，请立即转人工并说明「紧急」。
